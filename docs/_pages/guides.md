Use these guides to configure an evaluation and understand its results:

- [Datasets and data formats]({{ "/datasets/" | relative_url }}) lists the supported adapters and the inputs each one expects.
- [Models]({{ "/models/" | relative_url }}) explains model wrappers and configuration.
- [CLI]({{ "/usage/#command-line-interface" | relative_url }}) covers the command-line workflows.
- [Metrics]({{ "/metrics/" | relative_url }}) describes evaluation and profiling outputs.

The [usage page]({{ "/usage/" | relative_url }}) also links the existing tutorial
notebooks and library examples. See [compatibility]({{ "/compatibility/" | relative_url }})
for supported task, modality, dataset, and framework combinations, or launch the
[interactive GUI]({{ "/gui/" | relative_url }}). Documentation for the earlier
DetectionMetrics release remains available in the
[legacy section]({{ "/DetectionMetrics/" | relative_url }}).
